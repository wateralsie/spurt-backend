# 프로젝트 문서 동기화

## 대상 문서

- **백엔드**: `docs/DALLAEM_API_SPEC.md` (구현 순서 체크리스트)
- **프론트엔드**: `docs/FRONTEND_PLAN.md` (미정, 생성 시 추가)

## 컨텍스트 판단

1. **현재 세션에 개발 작업 내역이 있으면** → 대화 컨텍스트 우선 활용 (git 조회 최소화)
2. **없으면** → git log/diff에서 최근 변경사항 파악

## 작업 순서

1. 대상 문서 읽기
2. 실제 구현된 코드 스캔 (`backend/src/`, `frontend/` 등)
3. 필요시 최근 커밋 확인: `git log --oneline -15`
4. 문서의 체크리스트 vs 실제 구현 비교:
   - `[ ]` → `[x]` 변경 필요한 항목 식별
   - 문서에 없는 새 구현 발견 시 추가 제안
5. 업데이트 제안 (변경 전후 비교)

## 출력 형식

변경사항을 명확히 보여주고, 사용자 확인 후 수정할 것.

```
## 발견된 불일치

### 백엔드 (docs/DALLAEM_API_SPEC.md)
- 완료로 변경: [ ] Bun + Hono 프로젝트 생성 → [x]
- 완료로 변경: [ ] Prisma 설정 + Supabase 연결 → [x]

### 프론트엔드 (docs/FRONTEND_PLAN.md)
- (문서 없음 또는 변경사항 없음)

수정할까요?
```
